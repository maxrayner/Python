# Password Security Checker

## About

This program's task it to ask the user for a password and check it against secure password features (listed below), and finally return a security score, and what improvements could be made

## Research

I conducted research into password security improvements. A secure password length should consist of 15+ characters long to avoid brute-force attacks. In this program, each password length minimum is 16 characters long to provide maximum security.

## How It Works

The program asks the user to enter a password and then analyses it against several criteria.

It checks:

* Password length
* Uppercase and lowercase characters
* Numbers
* Special characters
* Whether the password appears in the common-password list
