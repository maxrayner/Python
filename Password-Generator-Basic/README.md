# Password Generator

## About

This python script generates a password with a customisable features using randomness to increase security

## Research

I searched online to find the module string which helped to efficiently place all alphabet and number characters into a placeholder


## How It Works

passwordgen.py:
* Asks user for desired length
* Asks user if wanting special characters
* Uses random library to choose a random index to get a character
* Adds to password
* Outputs password
